# おっ！サン SUN BONUS

通常ステージに追加する、プレイヤーに有利なボーナスイベント。
以前の専用チャレンジ・妨害・HP・接触ダメージは撤去済み。
操作、既存ステージ、スキン、SIZEの成長式、通常の制限時間・報酬・画面構成を維持する。開催版のみ目標とクリア待機条件を調整する。

## イベント

通常コイン（内部ID `coin`）とは別のレア太陽（`sunToken`）を使用。
虹色の丸い太陽に8色の光線を付けた独自のベクターアイテムで、他社キャラクターとは別物。
通常プレイ開始時に2個、以降2秒間隔で追加し、盤面上は最大3個。ボーナス中は追加しない。
3枠が埋まっていても、画面外の未取得太陽を2秒の出現タイミングで表示範囲に再配置する。
配置候補はプレイヤーの吸引範囲から画面上約100px外側を優先し、他の太陽との重なりを避ける。
太陽だけがSUNゲージを増やす。通常コインとボーナス由来の★では増えない。
太陽を集めると `normal → sunBonusEntering → sunBonusActive → sunBonusEnding → normal`。
必要数は毎回5個。
初回のみ救済あり。プレイ開始20秒、残り12秒、またはTARGET到達のいずれかで、未発動なら自動で開始する。ポーズ時間は数えない。2回目以降は太陽5個が必要。
ボーナス由来の★（eventOnly）は終了後もゲージに加算せず、スコア獲得のみ行う。
Game.stateはplayのままでプレイを止めない。制限時間が0でも、進行中の登場・ボーナス・退場は最後まで継続する。
開催版のステージ1〜10の目標は20,000 / 22,000 / 23,000 / 24,000 / 25,000 / 26,000 / 27,000 / 28,000 / 29,000 / 30,000点。開始時の開催状態で判定を固定し、表示と結果判定を統一する。通常版は元の目標を使用する。
30秒前後からの達成を目安にした得点目標で、最低プレイ時間による終了制限は設けない。TARGET到達でクリアを確定し、進行中のボーナス退場後に終了する。初回が未発動ならTARGET到達時に開始する。
CLEAR TIMEは目標に到達した瞬間。ポーズ・イントロ・その後のボーナス待機時間は含めない。既存の保存記録は削除しない。
計測用 `node scripts/measure-sun-balance.cjs [playwrightパッケージのパス]` は390×844画面・初期スキン・ブーストなし・3乱数系列で実ゲームの更新処理を実行する。0.4秒ごとに近い取得可能アイテムへ65%速度で移動する自動操作。早期終了と目標到達による初回発動は無効化して得点曲線を比較する。人間の操作、端末性能、購入ブーストによる差があり、実機プレイ時間を保証するものではない。
BEST TIMEはステージ別・通常/SUN別に保存し、短縮時にNEW BEST TIMEを表示する。従来のスコア記録は保持する。
登場0.65秒、ボーナス8秒、退場1秒。ポーズ中はイベント時間と移動も停止する。
有効中は吸引範囲1.5倍、スコア2倍。通常コインの抽選重みは変更しない。
既存のスキン・バキューム・購入ブーストへ乗算し、終了後はイベント分だけを取り除く。
開始時40個、その後毎秒10個の★/花がキャラクター付近からプレイヤー周辺へ広がる。
ボーナスで生成した★/花はscoreOnly。基本点は通常の半分。コンボ・購入ブースト・SUN倍率を乗算した最終加点の小数部分を切り捨てる。
コンボ・回収演出は維持し、SIZEとバキュームは増やさない。
イベント終了後に残った分も同じ扱い。通常アイテムとレア太陽の成長・バキューム加算は維持する。
追加報酬アイテムは最大100個、レア太陽は最大3個。通常オブジェクトを上書きしない。
ボーナス中に拾ったレア太陽は次回に持ち越す。終了後、その個数からゲージを再開し、同一ゲームで再発動できる。
最高記録は通常版とSUN版で分離。開始時にコラボが有効なゲームはSUN BESTに保存し、途中の期限切れでも分類を維持する。
ステージ進行・報酬は従来どおり共通。既存の記録は由来を判別できないため変更しない。
ズームアウト時もレア太陽の表示サイズを確保する（当たり判定は変更しない）。
画像読み込み失敗時はキャラクター表示のみ隠し、ゲームとボーナス効果は継続する。
残った追加アイテムは通常の吸引で回収可能。ゲーム終了・タイトル帰還・期限切れで追加分を片付ける。

## IP・画像

おっ！サンはDOMの独立した表示レイヤーで、物理判定や吸引対象に一切登録しない。
攻撃、ダメージ、衝突、妨害、敗北、独自セリフ・音声はない。
PNGは元バイト列のまま使用し、縦横比を維持。パーツ・表情・色・背景を加工しない。
画像全体を画面端から移動させ、ボーナス中はゆっくり上下左右に動かす。
終了時は画面外へ移動する。ルール説明とボーナス中の©表記はキャラクター画像内のものを使用し、画像の外には追加しない。

## ローカル確認

`node scripts/preview-ohsun.cjs` を起動し、
`http://127.0.0.1:4173/?ohsun-preview=1` を開く。
スマホで確認するときは `node scripts/preview-ohsun.cjs --lan` を起動し、同じWi-Fiから `http://PCのLANアドレス:4173/` を開く。
LANモードだけ配信HTMLにコラボ有効化フラグを挿入する。通常ビルドや開催日時設定は変えない。
同一ネットワークからアクセス可能になるため、信頼できる家庭内ネットワーク等でのみ使用し、確認後はサーバーを停止する。ポートのインターネット公開は不要。
通常のCONTINUE/STAGE SELECTから開始してレア太陽を5個集める。
プレビューも通常のステージ進行・コイン・記録を保存するので、独立したブラウザプロファイルでの確認を推奨。
`npm run build:collab-preview` はwww/に確認用ビルドを作る。一般公開しない。
`npm run sync:ios`（または `npm run sync`）は現在のwwwがコラボ確認版なら、その状態を維持して再ビルド・同期する。
コラボ有効版を明示する場合は `npm run sync:ios:collab`。日時設定に従う通常ビルドへ戻す場合は `npm run sync:ios:normal`。
ビルドテストとブラウザテストの通常版はOSの一時フォルダに生成し、wwwやiOSの同期済みファイルを変更しない。
URLのプレビュー指定はlocalhost系ホストのみ受け付ける。

## 開催・終了

現在はohsun.config.jsの OHSUN_COLLAB_ENABLED=true、manual=true により、手動終了までコラボを有効にする。
別PCでも `npm ci` → `npm run sync:ios` でコラボが反映される。特別なプレビュー指定は不要。
自動期間管理へ変更する場合はmanual=falseにし、startsAt/endsAtを `YYYY-MM-DDTHH:mm:ss+09:00` 形式で設定する。manual=falseかつ日時未設定なら通常ビルドにコラボを含めない。
開催版：`npm run build:web`。iOSへの同期：`npm run sync:ios`。
終了日時は含まない。期限切れではイベントの効果と画像を解除し、通常プレイをそのまま継続する。
端末時計による判定であり、旧インストール内の素材を遠隔削除するものではない。

終了版：OHSUN_COLLAB_ENABLED=false にして `npm run sync:ios:normal`（Webのみなら `npm run build:web`）。manual=trueでもenabled=falseが優先され、素材も配布から外れる。
www/collaborations と www/public/collaborations がないことを確認し、www/の内容で置換配信する。
Webの前回配信ファイルも残さない。iOSは同期・終了版配信を行う。
終了版では素材と専用コード/CSSを配布しない。source/reviewはどのビルドにも含めない。
リポジトリやpublic/全体をそのまま配信しない。
